# Security Policy

## Reporting a Vulnerability

Do not open a public issue containing credentials or an exploitable vulnerability. Use GitHub's private vulnerability reporting feature for this repository when available, or contact the maintainers privately through the organization profile.

Never include `auth.json`, access tokens, refresh tokens, API keys, sync keys, WebDAV passwords, or unredacted server logs in a report.

## Supported Versions

Security fixes are applied to the latest published release. The project refuses to modify unknown future `codex-auth` registry schemas.
