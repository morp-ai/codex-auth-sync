# Cloudflare Workers + D1

Cloudflare Workers and D1 can host the synchronization API without maintaining a server. The payload remains end-to-end encrypted. Free-tier limits and pricing are controlled by Cloudflare and may change.

## Prerequisites

- A Cloudflare account
- Node.js and npm
- The API token generated by `codex-auth-sync keygen`

## Deploy

```sh
cd deploy/cloudflare-worker
npm install
npx wrangler login
npx wrangler d1 create codex-auth-sync
cp wrangler.toml.example wrangler.toml
```

Copy the returned D1 database ID into `wrangler.toml`, then run:

```sh
npx wrangler d1 migrations apply codex-auth-sync --remote
npx wrangler secret put SYNC_API_TOKEN
npm run deploy
```

Enter the generated API token when prompted for `SYNC_API_TOKEN`. The deployment prints a URL similar to:

```text
https://codex-auth-sync.<account>.workers.dev
```

Configure each node:

```sh
codex-auth-sync init \
  --server 'https://codex-auth-sync.<account>.workers.dev' \
  --api-token '<API token>' \
  --sync-key '<sync key>' \
  --cluster personal \
  --interval 15
```

## Request Usage

Each daemon performs one pull cycle per configured interval and pushes only when local state changes. At 15 seconds, one continuously running node performs approximately 5,760 pull requests per day. Increase the interval for large fleets or use the built-in service over a private network.

## Local Validation

```sh
npm run check
npm run dev
```

Do not commit `wrangler.toml` if it contains environment-specific identifiers you do not want to publish.
